# 💪 Летняя программа — масса + лёгкая сушка

Статический сайт с программой тренировок на 4 дня в неделю, трекингом подходов и анкетой уровня. Прогресс сохраняется локально в браузере (`localStorage`).

## Что внутри
- **Программа** — 4 дня: Руки+Пресс · Грудь+Спина · Ноги · Кардио (HIIT). Отмечаешь выполненные подходы, записываешь вес/повторы, видишь прогресс дня.
- **Анкета** — тест уровня (отжимания, приседания, подтягивания, планка) + любимые/нелюбимые группы. Считает уровень и даёт рекомендации.
- **Прогрессия & питание** — план нагрузок по неделям лета и правила питания без подсчёта калорий.

## Файлы
```
index.html   — разметка
styles.css   — стили (тёмная тема)
data.js      — ВСЯ программа (правится здесь)
app.js       — логика и трекинг
```
Чтобы поменять упражнения/подходы — редактируй только `data.js`.

## 🚀 Деплой на GitHub Pages

1. Создай репозиторий на GitHub (например `summer-gym`).
2. Залей файлы из этой папки в корень репозитория:
   ```bash
   cd summer-gym
   git init
   git add .
   git commit -m "Летняя программа: сайт с трекингом"
   git branch -M main
   git remote add origin https://github.com/<твой-логин>/summer-gym.git
   git push -u origin main
   ```
3. На GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`, **Save**.
4. Через ~1 минуту сайт будет доступен по адресу:
   `https://<твой-логин>.github.io/summer-gym/`

Открывай эту ссылку с телефона в зале и отмечай подходы.

## Локальный запуск
Просто открой `index.html` в браузере (двойной клик) — всё работает без сервера.
